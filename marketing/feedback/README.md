# Player feedback

Players leave feedback through Roblox's own window (the lobby's 📝 mailbox and every result card's 📝 button).
It only shows in Creator Hub → your experience → Audience → Feedback; there's no API for it. To have it read,
use the **export** button (top right of that page) to download the `.csv`, then upload it here
(github.com → this repo → this branch → `marketing/feedback/` → Add file → Upload files).
